# 控制台设计系统（仪器风）

视觉基准：Teenage Engineering / Panic 式仪器控制台——整台界面是一台「精密主机」，不是网页。

## 核心元素

- **米色机箱**：底色 `#e8e4d8` / 面板 `#f3efe4`，四角螺丝（radial-gradient 金属钉）
- **琥珀示波屏**：技术卡片区域暗底（近黑暖色）+ 琥珀信号色 `#E8A33D` + 扫描线质感
- **丝印标签**：小号等宽大写字母、宽字距（`letter-spacing:.15em+`），如 `CAL OK`、`CH-01`
- **单一 accent**：每模块一个主题色——推理/训练用信号橙 `#FF4D00`，K8s 用工业蓝 `#326CE5`（品牌致意）。accent 只用于强调，不大面积铺
- **等宽读数**：所有数字读数用 IBM Plex Mono，跳动时逐帧更新
- **模块矩阵**：技能树节点 = 插板式模块卡（斜纹遮蔽=锁定，红 LED=锁定，琥珀 pulse=可解锁，绿 CAL OK 钢印=已校准），依赖 = 跳线（虚线 SVG）

## 字体

- 读数/标签/按钮：IBM Plex Mono（Google Fonts CDN）
- 中文正文：系统字体栈即可

## 硬约束

- 正文 ≥14px、标签/丝印 ≥10px（装饰性）~12px（功能性）、对比度 ≥4.5:1
- 反 AI slop：禁紫渐变、禁 emoji 图标、禁「均匀深蓝底+通用霓虹 glow」、禁圆角卡片+左色条
- 中文「」引号，不用 ""
- 单文件 + 同目录 content.js，file:// 双击即开；无构建、无后端；`<link rel="icon" href="data:,">` 消除 favicon 404

## 布局骨架（1440×900 基准）

1. 机头：品牌 + 机型/阶段丝印 + 进度（已校准 n/N）+ 沙盒通关计数 + RST 按钮 + 状态 LED + 时钟
2. 技能矩阵：grid 分区（丝印支线名），模块卡按 grid 绝对定位，SVG 跳线层在下
3. 技术卡片（示波屏）：点模块展开，左侧六段文本 + quiz，右侧图解区（Canvas/CSS 动画）
4. 沙盒区：通道切换（CH-01/02/03）+ 参数面板（滑块/开关/选择器）+ 显存/容量分段条 + 算式追踪（等宽逐行）+ SLA 判定 + 通关钢印

参照实现：`assets/console-template.html`，直接克隆改。
